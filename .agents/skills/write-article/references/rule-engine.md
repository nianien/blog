# 规则引擎文章的专项核验

仅在文章以规则引擎实现、演示场景或性能比较为证据时使用；其他主题不要求这些检查。本文件补充专项核验，通用内容、行文与验收标准仍以根目录 AGENTS.md 为准。

- 区分内核执行能力、UI 表示模型和实际交互界面；不能以存在 UI AST 证明已有可操作页面
- 核对节点组合、条件短路、串并行、循环边界、节点参数、结果转换及缓存作用域，只检查正文实际作出的主张
- 对编辑模型与执行模型核对编译方向、合并或展开、执行路径映射，不凭示意图认定两者逐节点同构
- 命中数约束明确统计直接子条件还是原子叶子；内部复合条件不能未经核对重复计数
- 性能比较记录引擎与 JDK 版本、硬件、负载、预热、并发和指标口径；只有压测代码不能写成已复现性能结论
- 真实演示截图核对数据库或可重放 fixture、命名空间、场景与规则 ID、版本、输入及预期结果；流程与条件树需要对应时保留选中节点信息
- 流程与复合条件需要同时展示时，让读者看清选中的流程节点及其条件树；展示编排能力时按正文主张选择组合深度，不为堆节点而堆节点
- 模拟动作、状态推进、真实业务操作和持久化结果分别说明；扩展示例不默认已进入演示库
- 升级文章按用户确认的价值主线组织；引擎名称、前作关系、继承与新增能力保持一致
